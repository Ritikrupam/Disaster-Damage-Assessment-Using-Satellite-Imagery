# Disaster Damage Assessment using Satellite Imagery

## Overview

This project focuses on automatic disaster damage assessment using Deep Learning and Computer Vision techniques on satellite imagery.

The system performs:

- Building Localization
- Damage Classification
- Semantic Segmentation
- Post-Disaster Analysis

Dataset Used:

- xBD Dataset
- xView2 Dataset

---

## Models Implemented

- U-Net
- VGG16 + U-Net
- EfficientNet-B0
- Attention U-Net
- Siamese Network
- DeepLabV3+
- ResNet-Based Segmentation
